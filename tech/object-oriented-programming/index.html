THE PAGE

What lives here

Object-oriented programming is about organising software the way we understand the world: as objects with state and behaviour that talk to each other. Done well, it keeps big systems readable. Done badly, it's just inheritance gone wrong — so the "when not to" matters as much as the "how".

This page covers the four classic pillars and the ideas that come after them: composition over inheritance, SOLID, UML and the design patterns that keep reappearing in real codebases. Examples come mostly from Java and C++, with notes on how each language treats the same idea differently.
