THE PAGE

What lives here

C is the language the rest of computing quietly stands on — UNIX, Linux, git, browser engines, and the embedded systems in everything around the room. Learning C means learning how your program actually works: what memory looks like, what a pointer really is, and what the compiler is doing between you and the machine.

This page collects the notes, small examples and mistakes that came with working through C in order. It starts at the first compile and climbs all the way up to dynamic memory and writing your own little libraries.
