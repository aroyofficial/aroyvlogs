THE PAGE

What lives here

Java has been the workhorse of backends and enterprise systems for decades — and its write-once-run-anywhere idea, built on the JVM, still powers Android apps and very large distributed systems. The language itself keeps moving: modern switch, records and streams make it a lot closer to 2026 than most people expect.

This page tracks the Java journey — setup and tooling, the core language, object-oriented design, collections and exceptions, and the modern additions. Code-first, with something small to compile at every step.
