binary_search.c 
// Binary search — O(log n) on sorted data
int binarySearch(int a[], int n, int x) {
    int lo = 0, hi = n - 1;
    while (lo <= hi) {
        int mid = lo + (hi - lo) / 2;
        if (a[mid] == x) return mid;
        if (a[mid] < x) lo = mid + 1;
        else hi = mid - 1;
    }
    return -1;
}
THE PAGE

What lives here

Data structures and algorithms are the part of programming that decides whether your solution runs in a blink or takes a blink per user. The goal isn't memorising algorithms — it's building intuition: seeing a problem and recognising its shape before writing a single line.

This page is the working DSA roadmap — complexity analysis first, then the classic structures in order, then the problem-solving techniques: recursion, greedy, dynamic programming. Practice problems and links will be added as each topic is worked through.
