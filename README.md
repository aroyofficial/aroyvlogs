# Vlogs with Arijit

A lightweight, responsive personal content hub for travel, festivals, food, technology and stories.

## Structure

- `index.html` — homepage and content hub
- `css/style.css` — global responsive design
- `js/app.js` — small site interactions
- `pages/durga-puja-2026/` — Durga Puja 2026 collection
- `netlify.toml` — Netlify static deployment configuration

## Design direction

This is intentionally a **content-first personal site**, rather than a dedicated Puja-only application. New collections can be added under `pages/` while the homepage remains the central hub.

## Deployment

The repository is ready for Netlify as a static site. Set the publish directory to the repository root (`.`); no build command is required.
